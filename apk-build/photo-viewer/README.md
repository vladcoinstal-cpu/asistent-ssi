# Galerie Foto Animată

Aplicație Android simplă pentru selectarea și afișarea mai multor imagini, package:
`com.numeletau.iadulascultarii`.

Funcții:
- selectare multiplă prin Android Storage Access Framework;
- JPG/JPEG, PNG, WebP, GIF, BMP, HEIC/HEIF și AVIF când codec-ul sistemului Android le suportă;
- navigare anterior/următor;
- moduri de afișare Fit, Crop, Stretch, Center;
- animații Fade, Zoom, Rotire, Slide;
- fără permisiune generală de acces la stocare și fără INTERNET.

Versiune: 1.0.0 (versionCode 1)
Target SDK: 35
Min SDK: 26
